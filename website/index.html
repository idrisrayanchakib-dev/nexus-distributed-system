Distributed Causality

Lamport Logical Clocks

Solves wall-clock drift in decentralized networks. Every message advances logical timestamps $L(e)$, guaranteeing deterministic causal partial ordering across all peers.

Rule: max(L_local, L_msg) + 1 O(1) Sync
Applied Security

Zero-Knowledge E2EE

Derives 256-bit symmetric encryption keys using PBKDF2HMAC with SHA-256 across 100,000 iterations. Derives 4-character room fingerprints for instant unauthorized packet rejection.

Cipher: Fernet Authenticated 256-bit Key
Binary Streaming

Chunked File Transfer

Direct peer-to-peer file transmission engine. Splits arbitrary files into 32 KB chunk envelopes and validates complete transmissions with cryptographic SHA-256 checksums.

Integrity: SHA-256 Checksum 32 KB Slices
Consensus Engine

Failover Voting Consensus

Leader-driven ballot coordination with automated fallback: if the election initiator disconnects, surviving peers timeout and compute consensus tallies locally.

Model: Leader + Fallback Anti-Tamper
Zero-Config Peering

Dual Auto-Discovery

Broadcasts UDP discovery beacons on port 60001 for seamless LAN auto-peering, combined with localized port scanning (6000-6030) for single-machine simulation.

Port: UDP 60001 / TCP 6000-6030 Auto Mesh
Thread-Safe Storage

Mutex-Locked Persistence
